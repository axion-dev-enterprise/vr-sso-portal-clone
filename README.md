# VR Benefícios SSO Portal UI/UX Clone

Reconstrução em altíssima fidelidade da interface e experiência de usuário do portal **VR Benefícios SSO / Gestão de Pessoas** ([sso-acesso.vr.com.br](https://sso-acesso.vr.com.br/)), utilizando a stack do **Next.js 15 + React 19 + Tailwind CSS + Lucide Icons**.

## 🚀 Funcionalidades

- **Identidade Fiel VR Benefícios**: Paleta de cores oficial (`#02d72f`, `#034d2e`, `#1b2126`), tipografia e layout responsivo Big Tech.
- **Autenticação Unificada SSO**: Modal acessível customizado com perfis de acesso para **Trabalhador**, **Empresa (RH)** e **Estabelecimento**.
- **Hero Slider Interativo**: Carrossel com 3 slides principais (*Automação RH*, *Economia PAT*, *CUFA Troco Solidário*).
- **Grid de Soluções Integradas**: Módulos para *VR Refeição*, *VR Alimentação*, *VR Auto*, *VR Ponto & Holerite*, *VR Mobilidade*, *VR Multi Benefícios*.
- **Zero Emojis & Ícones SVG Vetoriais**: 100% Lucide Icons com padronização geométrica.

## 🛠️ Tecnologias

- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS v3.4**
- **Lucide Icons**
- **TypeScript**

## 💻 Como Rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3050` no seu navegador.
