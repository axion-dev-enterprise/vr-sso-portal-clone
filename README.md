# VR SSO Portal & AXION Enterprise UI Template

Reconstrução de alta fidelidade da interface e experiência de usuário do portal **VR Benefícios SSO** ([sso-acesso.vr.com.br](https://sso-acesso.vr.com.br/)), utilizando a stack do **Next.js 15 + React 19 + Tailwind CSS + Lucide Icons**.

## 🚀 Funcionalidades

- **Alternador de Marca Instantâneo**: Alterne entre a identidade visual da **VR Benefícios** (`#02d72f`, `#034d2e`) e **AXION Enterprise** (`#09090b`, `#121217`).
- **Autenticação Unificada SSO**: Modal acessível customizado com perfis para **Trabalhador**, **Empresa (RH)** e **Estabelecimento**.
- **Hero Slider Interativo**: Carrossel com 3 slides (*Automação RH*, *Economia PAT*, *CUFA Troco Solidário*).
- **Mapeamento de Produtos AXION**: Alternador de visão de produtos para pré-visualizar *AXION Pay*, *AXION Flow*, *AXION Voice*, *AXION PDV*, *AXION Security*, *AXION Hub*.
- **Zero Emojis & Ícones SVG Vetoriais**: 100% Lucide Icons com padronização geométrica.

## 🛠️ Tecnologias

- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS v3.4**
- **Lucide Icons**
- **TypeScript**

## 💻 Como Rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3050` no seu navegador.
